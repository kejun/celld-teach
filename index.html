celld：无共识的分布式状态层

Deno 官方 2025-04 开源的 Rust 守护进程：在自有机器上跑 Cloudflare Workers + Durable Objects，用对象存储当控制平面，不引入 Paxos / Raft。本课程围绕三条机制支柱展开——条件写所有权、epoch fencing、RPO=0 确认规则。

分布式系统数据库架构SQLite / LTXRustAgent 工程
MISSION · 学完你能做什么
  • 讲清 celld 的三条核心机制：conditional-write 所有权、epoch fencing、RPO=0 确认规则
  • 解释 fleet proof vs bucket proof 两种持久化路径，以及为什么 2 节点是分水岭
  • 对比 celld 与传统分布式数据库（Paxos/Raft 多副本）的设计取舍——为什么 celld 敢不要共识
  • 梳理 LTX 血统（Litestream → rustyriver → celld-ltx）及它在复制链中的角色
  • （元层）把「对象存储条件写 = 免费的领导权仲裁」迁移到自己的系统设计
